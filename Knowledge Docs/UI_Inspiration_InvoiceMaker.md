# UI Inspiration: InvoiceMaker iOS App Design

**Source:** [Behance Gallery](https://www.behance.net/gallery/191965875/InvoiceMaker-iOS-Mobile-App-Design?tracking_source=search_projects|finance+tracking+app&l=16)

## Overview
The design presents a sophisticated, high-contrast **Dark Mode** interface that perfectly complements the Savery brand identity. It utilizes **Electric Lime (`#C8F100`)** as its primary accent color, providing a fresh, energetic, and modern "pro" feel.

## 1. Overall Visual Style & Aesthetic
* **Theme:** Modern, minimalist Dark Mode with high-tech accents.
* **Mood:** Energetic, premium, and clean. It avoids the traditional "boring bank app" look.
* **Spacing:** Generous use of "black space" (negative space) creating a breathable, high-end feel.

## 2. Color Palette
* **Primary Accent:** Electric Lime (`#C8F100`) - Used for all major CTAs, active tab states, and progress indicators.
* **Secondary Gradient:** Deeper Green/Lime (`#A6E600`) - Used alongside the primary accent to create depth.
* **Backgrounds:** Deep Pitch Black (`#000000`) for the primary backdrop, with Very Dark Gray (`#1A1A1A`) used for card surfaces.
* **Text:** Pure White for headings and Light Gray for secondary labels/body text.

## 3. Screens & Components
* **Navigation:** Top headers feature large, bold titles and minimalist action icons (e.g., a simple `+` for adding actions).
* **Cards:** High-radius rounded corners (approx. 24-32px) that create a friendly yet modern container for information, contrasting with the dark theme.
* **Buttons:** Pill-shaped primary buttons utilizing the lime background with black text for maximum contrast and tap affordance.
* **Tabs/Switchers:** Pill-shaped segmented controls (e.g., filtering views) that use high contrast to show the selected state.
* **Data Visualization:** Simple, rounded-top bar charts in Electric Lime. This makes financial data highly readable and visually striking against the dark background.

## 4. Typography & Iconography
* **Fonts:** A clean, modern sans-serif (resembling SF Pro) with large, bold headings establishing a clear and strong hierarchy.
* **Icons:** Thin-stroke, minimalist iconography that feels custom, sleek, and high-tech.

## 5. Unique Patterns & Layouts
* **Large Emotional Typography:** Oversized text is used to describe "Problems" and "Solutions", adding a storytelling element to the UI flow.
* **Glassmorphism:** Subtle use of translucent overlays and blurred background elements adds depth to the dark theme without cluttering it.

## Takeaways for Savery
This design language provides an excellent blueprint for Savery's "AI-native financial clarity engine". It is bold, sharp, and optimistic, aligning perfectly with Savery's branding (which also heavily relies on `#C8F100` and dark mode principles). Key elements to adopt include the high-contrast lime-on-black aesthetic, the pill-shaped UI components, and the generous negative space for clarity.
